# 📅 Sports Scheduler

A web application for organizing and managing sports sessions. Players can create and join sessions, while admins manage sports and view analytics.

## ✨ Features

- 🔐 User authentication (JWT)
- � Create and manage sports (Admin)
- 🎮 Create and join sports sessions
- 📊 Analytics and reports (Admin)
- 📅 Session management with cancellation

## 🛠️ Tech Stack

**Frontend:** React 19, Vite, Tailwind CSS, React Router  
**Backend:** Node.js, Express, PostgreSQL, Sequelize, JWT

## 🚀 Quick Start

### Backend Setup

```bash
cd backend
npm install
# Configure .env with database credentials
npm run dev  # Runs on http://localhost:5000
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev  # Runs on http://localhost:5173
```

### Database Setup

```sql
CREATE DATABASE sports_scheduler;
```
