HOW TO TAKE SCREENSHOTS:
-------------------------
- Use Windows Snipping Tool (Win + Shift + S)
- Or use browser DevTools (F12) and set device to 1920x1080
- Save each screenshot with the exact name listed above
- Recommended resolution: 1920x1080 or 1440x900

AFTER ADDING SCREENSHOTS:
-------------------------
1. Commit the screenshots to your Git repository
2. Push to GitHub
3. The README.md will automatically show them!
